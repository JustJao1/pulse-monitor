Visão de operação

Para quem administra sites e sistemas: descubra quando uma loja virtual, um login ou uma API deixa de responder. O Pulse registra a falha para você investigar.

Cadastrar um serviço para monitorar ↓
Primeira vez no Pulse? Faça uma checagem em 4 passos
  1. Cadastre: informe nome, endereço e resposta esperada (200 significa sucesso).
  2. Verifique: teste os monitores e veja a latência, o tempo que o serviço levou para responder.
  3. Investigue: simule uma queda para registrar HTTP 503 e veja o incidente aparecer.
  4. Acompanhe: confira o histórico e exporte registros. Nesta demonstração, só endpoints fictícios e verificações com a página aberta.

Experimente uma queda controlada: o servidor de exemplo retorna HTTP 503, e o Pulse registra o incidente. Nenhum site real será afetado.
